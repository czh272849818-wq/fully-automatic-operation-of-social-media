# 自媒体全自动运营

把账号当作可测量的媒体业务运营。每天的核心不是“发更多”，而是用一条主选题验证一个增长假设，并把结果沉淀为可复用资产。

## 工作顺序

1. **先复盘，再生产。** 先读取前一天已发布内容的数据；没有权限或页面未打开时写明“数据暂缺/数据缺口”，不能猜成 0。
2. **每天只测试一个增长假设。** 明确今天改变的变量（选题、标题、封面、前 2 秒、结构或 CTA）和要验证的深度指标。
3. **定位漏斗断点。** 只能从分发、包装、留存、互动、信任、转化、商业化七类中选主要断点。播放量、曝光量、点赞量只能作为表层信号。
4. **一案多平台适配。** 一个真实 AI 商业案例或工作流，分别改写为中文图文、中文轮播、英文 X 内容和真实英文屏幕录制视频；不要跨平台原样复制。
5. **发布动作受控。** 可准备并编辑到发布前检查状态；任何公开发布、评论、点赞、删除或账号设置变更，都要在动作发生前取得用户当次明确确认。
6. **次日归因。** 记录选题、标题、素材、平台版本、数据、事实/推断/Vince 判断，并决定放大、修改或淘汰。

## 事实与内容标准

- 新闻或产品内容优先使用最近 24–72 小时的高信号来源，必要时扩展到 7 天。记录来源 URL、日期、来源类型、发生了什么、为什么重要、用户能做什么。
- 明确区分**事实**、**推断**和**Vince 判断**；不要把新闻稿、赞助内容或官方声明包装成独立报道。
- 四个内容支柱：案例拆解、工作流教程、工具判断、创始人/IP 实验。默认定位为“用第一性原理拆解真实 AI 商业案例，给普通人、小团队和企业可执行的 AI 工作流”。
- 内容应给出具体场景、证据、可复制步骤和限制条件，避免未经证实的收入承诺、绝对化表述和无标识 AIGC。

## 输出要求

策略、诊断和日报按以下顺序组织：结论；第一性原理分析（目标、约束、关键变量、底层逻辑）；最优解；执行步骤；杠杆点；风险与误区。

日报必须覆盖：小红书、抖音、快手、视频号、X、TikTok。每个平台记录表层数据、深度数据、漏斗断点和下一步验证指标；深度数据不可见时写出需要进入的具体后台页面。

## 不可违反的运营边界

- 快手当前暂停：除非用户明确恢复，不登录、不编辑、不上传、不发布。
- TikTok 默认必须是真实英文屏幕录制视频；不能用静态图卡伪装。
- 抖音、视频号、TikTok 的音乐需为已核验、英文、有冲击力或史诗感的曲目；不能冒充曲名/作者，也不能使用“为爱痴狂（DJ版）”。
- 最终公开发布仍需用户当次确认；本 Skill 的 GitHub 打包和推送属于用户已授权的本次任务。

## 复盘升级

同一流程问题出现两次，写入问题清单；出现三次，修改 SOP。每次结论必须指向一个今天能执行、明天能验证的动作。

# 内容模板

## 案例拆解

1. 反常识结论。
2. 案例背景与可核验数字。
3. 需求、供给、分发、支付意愿。
4. 普通人可复制的三步。
5. 适合谁、不适合谁。
6. 工具和限制。
7. 今日行动。

## 工作流教程

场景 -> 输入材料 -> AI 分工 -> 具体步骤 -> 输出样例 -> 常见错误 -> 可复制清单。

## 证据型短视频

时长 55–70 秒；结构为 0–2 秒结论/冲突，2–7 秒来源与来源类型，7–18 秒发生了什么，18–35 秒真实产品输入/过程/输出，35–50 秒第一性原理拆解，50–62 秒当天动作，62–66 秒 Vince 立场。每条结论绑定来源 URL 和画面，明确事实、推断、判断。

## 小红书轮播

第 1 页强结论；中间页给证据、机制和步骤；最后一页给 SOP、限制和行动。中文 9:16，优先收藏价值。

## X Thread

英文结构：Claim -> Case -> Mechanism -> Misunderstanding -> Workflow -> Tool stack -> Risk -> CTA。

## 选题筛选

优先：真实案例、明确数字、冲突、可复制动作和目标人群；拒绝无法核验的收入截图、单纯工具罗列、无行动结论和脱离账号主线的热点。
